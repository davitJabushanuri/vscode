# Changelog

## [1.0.0]

- Initial release of Kodik
- AI assistant that can use your CLI and Editor
- Support for multiple AI providers (Anthropic, OpenAI, OpenRouter, AWS Bedrock, Google Gemini, and more)
- File editing with diff view and streaming animations
- Terminal command execution with interactive input support
- Task management with history and checkpoints
- Context mentions (@file, @folder, @url, @problems) for enhanced workflows
- Model Context Protocol (MCP) support for custom tools
- Browser automation for debugging and testing
- Image support for vision-enabled models
- Auto-approve settings for streamlined workflows
- Plan/Act mode for task planning before execution
